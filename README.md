# Haiku Generator

A simple Python script that generates random haikus from themed word banks.

## Requirements

- Python 3.10+
- No external dependencies required

## Usage

```bash
# Default theme (nature)
python haiku_generator.py

# City theme
python haiku_generator.py city
```

## Example Output

```
autumn leaves are falling
petals drift across still water
stars begin to glow
```

## Available Themes

- `nature` — mountains, rivers, seasons
- `city` — streets, neon, crowds

## Extending

Add new themes by editing the `THEMES` dictionary in `haiku_generator.py`.
